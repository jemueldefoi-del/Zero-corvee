# Zéro Corvée

Guides d'achat indépendants pour confier les tâches ménagères aux machines.

Site en ligne : https://jemueldefoi-del.github.io/Zero-corvee/

Le site est généré par `source/build.py` (contenu dans `source/content*.py`).
Pour le régénérer : `cd source && python3 build.py`, puis copier le contenu de `source/site/` à la racine du dépôt.
